# 🚀 Patient Health Portal

## 🌟 Overview
Designed and developed a secure Patient Health Portal emphasizing medical record data visualization. The goal was to create a modern, reliable web interface that enhances patient engagement and streamlines information access for users.

## 🛠 Tech Stack
Frontend UI:
- React.js & Vite (Lightning-fast frontend rendering)
- Tailwind CSS (Custom, responsive utility styling)
- Data Visualization UI (Medical record dashboards)

Backend & Security:
- MongoDB (Robust data management for medical records)
- Okta IAM (Secure Identity and Access Management)

## ✨ Features

1️⃣ High-Grade Security
- Integrated Okta Identity and Access Management
- Strict authentication protocols for sensitive patient data
- Secure login and session management

2️⃣ Data Visualization
- Clean, readable medical record dashboards
- Easy-to-understand health metrics for patients
- Interactive charts and data points

3️⃣ Robust Architecture
- MongoDB for efficient healthcare dataset management
- Scalable data structures for complex medical info
- Reliable backend-to-frontend data flow

4️⃣ Modern UX
- Highly responsive interface built with React and Vite
- Optimized for speed and performance
- Mobile-friendly design for healthcare on the go
